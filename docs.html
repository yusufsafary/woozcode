Windows

currentCommit() returns the open Commit. Windows last 14,400 seconds. Commit 1 ends at the first 4-hour UTC boundary after genesis; later Commits align to boundaries. isSealed(commit) reports whether a Commit has sealed.

Free mint

Read questionFor(wallet) on the Snippets contract. It returns (a, b, op): op 0 means a + b, op 1 means a − b, op 2 means a × b. Call mintFree(answer) from the wallet itself (contract calls are rejected). One free Snippet per wallet per Commit; the wallet must hold an Agent ID.

Paid mint

After the free Snippet, call mintPaid() with the exact value from priceFor(wallet): 0.0002 BNB for Snippets 2 to 5, 0.0004 BNB for 6 to 10, per Commit.

Claim

For a sealed Snippet you own, read feeFor(tokenId) and claimAmount(tokenId) on the Claim contract, then call claim(tokenId) with exactly that fee as value. One claim per Snippet, ever. Full machine-readable instructions live in the skill file.
